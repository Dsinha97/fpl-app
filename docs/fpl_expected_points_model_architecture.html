Dynamic Bayesian Engine: Gamma-Poisson Filtering & Dixon-Coles

To adapt dynamically after each scored gameweek without overfitting to small-sample noise, Engine v2.0 replaces static historical per-90 rates with an online Conjugate Gamma-Poisson (PEWMA) State-Space Filter and a dynamic Dixon-Coles Team Strength Model. Below, explore how exposure-gated discounting preserves prior stability while reflecting genuine tactical form, and calculate dynamic team clean sheet probabilities.

Gamma-Poisson Conjugate Update Equations

// Prior State Initialization (t=0)
α_0 = (μ_0)^2 / v_0 = μ_0 · (n_eff,0 + σ^2/τ^2)
β_0 = μ_0 / v_0 = n_eff,0 + σ^2/τ^2
// Exposure-Gated State Transition (t-1 -> t)
α_{t|t-1} = δ^{e_{i,t}} · α_{t-1}
β_{t|t-1} = δ^{e_{i,t}} · β_{t-1} (δ ∈ [0.94, 0.97])
// Closed-Form Posterior Update on Event y_{i,t}
α_t = α_{t|t-1} + y_{i,t}
β_t = β_{t|t-1} + ẽ_{i,m,t} (ẽ = e_{i,t} · F_{i,m,t})
E[θ_{i,m,t} | D_t] = α_t / β_t

Opponent-Adjusted Exposure Safeguard

Conditioning the update rate denominator on fixture difficulty ($\tilde{e}_{i,m,t} = e_{i,t} \cdot F_{i,m,t}$) prevents the engine from over-reacting when a player hauls against weak opposition.

Example: Striker 1.2 xG vs Weak Defense (F_attack = 1.35)
Raw Exposure $e_{i,t} = 1.0 \implies \tilde{e}_{i,m,t} = 1.35$
The denominator inflates by $1.35$, properly attributing the scoring surge to the favorable fixture rather than permanently inflating the player's underlying talent rate.

Unified 3-State Hurdle Model & Component Deconfounding

By replacing the hard-gated $\ge 1,200$ prior minute eligibility cliff with a continuous 3-State Hurdle Model ($P(M=0)$, $P(1 \le M < 60)$, $P(M \ge 60)$), Engine v2.0 eliminates bench leakage while accurately pricing substitute cameos. Furthermore, bonus points ($\text{bBPS}_{90}$) and defensive contributions ($10$ CBIT / $12$ CBIRT) are decoupled from finishing variance using exact Negative Binomial tails.

State 0: Non-Appearance
P(M = 0)

Derived via hierarchical prior logit offset and reserve goalkeeper masks ($<2\%$ owned GKs $<£5.0\text{m} \implies x\text{Mins} = 0$). Collapses non-appearance point leaks.

State 1: Cameo Substitute
P(1 ≤ M < 60)

Evaluates substitute appearance probability conditionally ($P(\text{Sub} \mid \text{No Start})$). Models cameo expected minutes ($\sim 18\text{ mins}$) without assigning full starter expectations.

State 2: Active Starter
P(M ≥ 60)

Top-14 power-scaled water fill ($\sum \min(\text{ceiling}_i, \lambda \cdot p_i) = 990$) guarantees full starter allocation without bench dilution.

Baseline BPS Decomposition ($\text{bBPS}_{90}$)

Neural Residual Architectures & Continual Online Learning

To capture temporal momentum and non-linear interactions without overfitting short FPL trajectories, Engine v2.0 deploys a Component-Level LightGBM Ensemble paired with a $\tanh$-Bounded Neural Residual Encoder (TCN/GRU/PatchTST). The neural head adjusts the Bayesian baseline by at most $\pm 35\%$, while Elastic Weight Consolidation (EWC) prevents catastrophic forgetting during weekly updates.

Component LightGBM Ensemble

fpl-predict Default

Trains separate GBDT models per scoring component (Goals, xA, CS, Cards, Saves, BPS, DC). Sums raw outputs via FPL rules to saturate the player-quality ceiling ($\rho_s = 0.695$, $54.9$ XI Pts).

Features: Rolling 3/5/10 GW metrics, venue, opponent xG, price velocity, positional depth rank.

Bounded Residual TCN / GRU

Neural Head

Encodes sequence history $X_{t-8:t-1}$ into context vector $h_{i,t}$. Clamps non-linear modulation through $\tanh(\cdot) \cdot c_{\max}$ to ensure mathematical safety on thin samples.

λ_NN = λ_Bayes · exp( tanh( w^T h_{i,t} ) · 0.35 )

Elastic Weight Consolidation (EWC) Loss

Prevents catastrophic forgetting when fine-tuning parameter weights on newly landed gameweeks by penalizing deviations in Fisher Information Matrix coordinates ($F_k$).

L_online(θ) = L_NLL(D_replay | θ) + (λ_EWC / 2) · ∑ F_k (θ_k - θ_k*)^2
• High Fisher Information ($F_k$): General aging curves, venue effects $\implies$ Frozen
• Low Fisher Information ($F_k$): Current-season tactical role shifts $\implies$ Flexible
